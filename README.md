# Hi, I'm Dimas 👋

I'm a Senior PHP Developer at Forest Interactive. Outside of work, I build AI agents, automations, and DeFi tools.

## 🔭 Currently building

**[kcurator.tech](https://kcurator.tech)** is a read-only analytics tool for liquidity providers on Krystal. It ranks concentrated-liquidity pools by fees, depth, and risk, lets you simulate a position, and keeps a public record of how its picks played out. The [showcase repo](https://github.com/dvictor357/kcurator-showcase) has screenshots and the architecture.
